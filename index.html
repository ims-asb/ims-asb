🔥 Firebase Setup

This connects everyone on your ASB team to the same live database. Free forever, no credit card.

  1. Go to console.firebase.google.com and sign in with your school Google account
  2. Click Create a project → name it IMS ASB Hub → disable Analytics → Create
  3. Click the </> web icon → name the app hub → click Register app
  4. Copy the firebaseConfig object (just the { ... } part, not the surrounding JS)
  5. In the left sidebar go to Build → Realtime Database → Create Database → Start in test mode → Enable
  6. Then go to the Rules tab and replace with: { "rules": { ".read": true, ".write": true } } → Publish
  7. Paste the config below and click Connect

⚙ Groq API Key
